# 루머스 AD 33 (RUMORS: AD 33)

타일 기반 2D 프로토타입. `index.html` 을 브라우저로 열면 바로 돌아갑니다
(빌드·설치 없음, 모듈 대신 일반 `<script>` 라서 `file://` 로 열어도 됩니다).

## 폴더

```
rumors-ad33/
├── index.html        게임 뼈대 — 화면 요소와 스크립트 순서만 있습니다
├── style.css         화면 배치와 UI
├── main.js           전체를 엮고 루프를 돌리는 핵심 코드
│
├── js/
│   ├── assets.js     그림 규격표(ATLAS·CHARS)와 이미지 로더
│   ├── map.js        장소 데이터(MAPS) · 충돌 굽기 · 포털
│   ├── player.js     사람과 짐승의 이동 · 충돌 · 애니메이션
│   ├── dialogue.js   대사와 소문 시스템
│   ├── audio.js      배경음 · 효과음 (파일 없으면 조용히 넘어감)
│   └── title.js      시작 화면 · 옵션 · 잠시 멈춤
│
└── assets/
    ├── images/       그림 (1_buildings ~ 8_characters)
    ├── audio/        소리 — 넣는 방법은 assets/audio/README.md
    └── videos/       start.mp4 — 시작 화면 배경
```

스크립트는 `assets → map → player → dialogue → audio → title → main` 순서로 읽습니다.
`js/map.js` 가 장소를 구울 때 `js/player.js` 의 인물 생성기를 쓰므로 순서를 지켜 주세요.

## 시작 화면

`index.html` 을 열면 `assets/videos/start.mp4` 가 화면 칸에 깔리고 그 위에
«START GAME · CHARACTER · OPTIONS · CONTROLS · CREDITS» 가 뜹니다.
그림을 받는 동안 첫 항목에 진행률이 나오고, 다 받으면 `[ PRESS START ]` 가 깜빡입니다.
방향키로 고르고 Enter, 마우스·손가락으로 눌러도 됩니다.
게임 중 `Esc`(휴대폰은 화면 오른쪽 위 `⏸`)를 누르면 같은 화면이 «잠시 멈춤» 으로 뜹니다.

- **제목은 영상에 새겨져 있어** 화면에는 차림표만 얹습니다.
  영상을 못 불러오면 글자 제목이 대신 나옵니다.
- **영상 소리는 쓰지 않습니다.** 영상은 늘 음소거이고, 시작 화면 음악은
  `assets/audio/bgm_title.mp3` 입니다. 오른쪽 위 스피커 단추로 켜고 끕니다.
- 옵션(배경음·효과음 볼륨, 인물 이름표, 규격 표시, 영상 재생)과 고른 주인공은 브라우저에 저장됩니다.
- 배경을 갈아 끼우려면 `index.html` 의 `<video src>` 만 바꾸면 됩니다.

### CHARACTER — 주인공 고르기

`assets/images/8_characters` 의 인물 **56명 전부**가 칸으로 깔리고, 고른 사람이 곧 주인공이 됩니다.
누르면 그 인물의 정면·측면·후면 세 장을 받은 뒤에 갈아 끼우므로 게임 도중에 바꿔도 됩니다.
목록은 `js/assets.js` 의 `CHARS` 표에서 그대로 옵니다 — 인물을 더 그려 넣으면 칸도 저절로 늘어납니다.

## 그림을 쓰는 방식

`assets/images/<묶음>/x1/<키>.png` 낱장을 그대로 불러옵니다.
**키 이름이 곧 파일 이름**이라, 같은 이름으로 그림을 덮어쓰면 코드는 건드릴 게 없습니다.

| 키 모양 | 폴더 |
|---|---|
| `f01_…` | `2_floors` (바닥 32×32) |
| `01_…` ~ `11_…` | `1_buildings` (건물) |
| `n01_…` | `4_nature` (나무·바위·우물) |
| `w_m_…` `w_r_…` `w_s_…` | `5_wall_kit` (벽 모듈) |
| `cw_…` `tr_…` `x01_…` | `7_expansion` (성벽·축대·소품) |
| `g01_…` `b01_…` | `8_characters` (인물 32×48) |

한 칸은 32px. 오브젝트는 **스프라이트 칸**(`cols`×`rows`)과 실제로 막히는
**충돌 발판**(`fw`×`fh`)이 따로 있고, 그 차이가 오버행이라 위쪽 줄로 걸어가면 건물 뒤로 가려집니다.

### 인물의 네 방향

인물 한 명은 세 장이 한 벌이고, 걷는 방향에 따라 자동으로 바뀝니다.

| 파일 | 언제 쓰나 |
|---|---|
| `g01_laborer.png` | 아래를 볼 때 (정면) |
| `g01_laborer_side.png` | 오른쪽을 볼 때. **왼쪽은 이 그림을 뒤집어** 재사용 |
| `g01_laborer_back.png` | 위를 볼 때 (후면) |

대각선으로 걸으면 좌우가 우선이라 측면 그림이 나옵니다.
`js/assets.js` 의 `CHARS` 에는 대표 키 하나만 적으면 되고, 로더가 세 장을 함께 받아 둡니다.
측면·후면 파일이 없는 인물은 정면 그림으로 대신 그리므로, 한 장만 있어도 깨지지 않습니다.

## 자주 하는 손질

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 오브젝트 하나 놓기 | `js/map.js` 의 `objs` 에 `{ a:'그림키', c:칸x, r:칸y }` 한 줄 |
| 말 걸 수 있게 하기 | 그 오브젝트에 `talk:['대사']` 추가 |
| 문으로 만들기 | `to:'장소키', at:[칸x,칸y], dir:'down'` 추가 |
| 인물 넣기 | `npcs` 에 `{ id, name, char:'g08_boy', at:[c,r], mode, lines:[…] }` |
| 소문 넣기 | `js/dialogue.js` 의 `RUMORS` 에 한 줄 → 인물에게 `rumors:['r13']` |
| 장소 넣기 | `js/map.js` 의 `MAPS` 에 같은 모양으로 한 덩이 |
| 주인공 바꾸기 | 시작 화면의 «CHARACTER». 기본값은 `js/title.js` 의 `DEFAULTS.hero` |
| 내 그림을 주인공으로 | 화면 오른쪽 «주인공 그림 넣기» (고른 인물보다 우선합니다) |
| 장소 음악 넣기 | `assets/audio/` 에 `bgm_<장소>.mp3` — 표는 `js/audio.js` |
| 시작 화면 문구 | `index.html` 의 `#titleTag`, 멈춤 문구는 `js/title.js` 의 `show()` |

## 조작

`W A S D` 이동 · `Shift` 달리기 · `Space` 말 걸기/들어가기 · `G` 규격 표시 켜고 끄기 ·
`Esc` 잠시 멈춤. `e.code` 로 받으므로 한글 입력 상태에서도 그대로 동작합니다.

## 휴대폰

손가락으로 하는 기기(`pointer:coarse`)로 열면 자동으로 바뀝니다.

- 화면 왼쪽 아래 **십자키**, 오른쪽 아래 **«살펴보기»**, 오른쪽 위 **⏸**(잠시 멈춤)
- 키보드 안내 칸은 숨고, 시작 화면 글자는 화면 칸 크기에 맞춰 작아집니다
- 화면 칸이 뷰포트 높이를 넘지 않게 잡아 두어서 **가로로 눕히면** 조작 단추까지 한눈에 들어옵니다
  (세로 390×844 에서 화면 322×221, 가로 844×390 에서 404×278)
- 달리기(Shift)와 규격 보기(G)는 아직 터치 단추가 없습니다

## 머리 위 표시

| 표시 | 뜻 |
|---|---|
| 이름표 | 가까이 가면 스며들듯 나타납니다 (90px 안에서 진하게, 165px 밖에서는 사라짐) |
| 이름표 색 | 분류마다 다릅니다 — 로마는 붉은빛, 종교 계층은 금빛, 상류층은 보랏빛, 짐승은 회색 |
| 금색 테두리 + 말풍선 | 지금 `Space` 로 말 걸 수 있는 사람 |
| 금색 `!` | 아직 못 들은 **소문**을 쥔 사람. 들으면 사라집니다 |

주인공 이름표는 조금 옅게 나오고, 옆에 사람이 붙으면 **스스로 비켜 줍니다**(겹치면 둘 다 못 읽으니까).
색과 거리는 `main.js` 의 `TAG_COLOR` · `TAG_NEAR` · `TAG_FAR` 에서 고칩니다.
옵션의 «이름표를 늘 보여 주기» 를 켜면 거리와 상관없이 모두 보입니다.
