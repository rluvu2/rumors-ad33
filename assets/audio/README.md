# assets/audio

소리 파일을 이 폴더에 아래 이름으로 넣으면 그때부터 자동으로 울립니다.
없는 파일은 조용히 건너뜁니다 (에러 없음).

## 배경음 (자동 반복)

| 파일 | 언제 | 길이 |
|---|---|---|
| `bgm_title.mp3`  | 시작 화면 | 3:04 |
| `bgm_alley.mp3`  | 하부 도시 골목 | 2:60 |
| `bgm_market.mp3` | 시장 광장 | 2:37 |
| `bgm_temple.mp3` | 성전 뜰 | 2:29 |
| `bgm_gate.mp3`   | 성문 | 2:14 |
| `bgm_grove.mp3`  | 올리브 뜰 | 2:49 |
| `bgm_roof.mp3`   | 옥상 | 1:50 |

**장소를 옮기면 옛 곡은 곧바로 멈추고 그 장소의 곡이 새로 걸립니다.**
파일이 없는 장소는 조용해집니다. 곡은 `loop` 로 이어 붙으니 끝과 앞이 자연스러우면 좋습니다.

## 효과음

아직 비어 있습니다. 아래 이름으로 넣으면 바로 울립니다.

| 파일 | 언제 |
|---|---|
| `sfx_step.wav` | 걸을 때 (달리면 더 빠르게) |
| `sfx_talk.wav` | 말을 걸 때 |
| `sfx_door.wav` | 문·계단으로 장소를 옮길 때 |

## 알아 둘 것

- 시작 영상 `assets/videos/start.mp4` 의 소리는 **쓰지 않습니다.** 영상은 늘 음소거로 돌아가고,
  시작 화면 음악은 이 폴더의 `bgm_title.mp3` 입니다.
- 브라우저 정책상 **화면을 한 번 클릭하거나 키를 한 번 눌러야** 소리가 시작됩니다.
  시작 화면 오른쪽 위 스피커 단추로 바로 켤 수 있습니다.
- 볼륨은 시작 화면의 «옵션» 에서 조절하고, 그 값은 브라우저에 저장됩니다.
- 이름을 바꾸거나 장소를 더 넣으려면 [`js/audio.js`](../../js/audio.js) 의 `BGM` · `SFX` 표만 고치면 됩니다.
